# 🚗 OmegaOS

OmegaOS est un système embarqué développé en Python pour l'Opel Omega B.

Le projet a pour objectif de créer un véritable ordinateur de bord moderne capable de communiquer avec le réseau CAN du véhicule, d'afficher les informations en temps réel, d'effectuer des diagnostics et de proposer une application mobile compagnon.

---

## Technologies

- Python 3
- PySide6 / Qt Quick (QML)
- Linux (Raspberry Pi OS)
- CAN Bus (MCP2515)
- FastAPI
- WebSocket
- Git

---

## Fonctionnalités prévues

- Interface graphique moderne
- Décodage CAN
- Diagnostic véhicule
- Historique des trajets
- Notifications iPhone
- API REST
- Maintenance
- Reverse Engineering CAN
